# relation-app-practice

## 概要
COACHTECH 教材 Tutorial 9-5「リレーション ハンズオン演習」で作成した成果物です。
リレーションを使って投稿との紐づけを行った
投稿の絞り込みや投稿の詳細表示が確認できるブログサイトを作成した

## 使用技術
- PHP 8.x
- Laravel 10.x
- Eloquent ORM（hasMany / belongsTo / belongsToMany）
- MySQL
-コーチテックのAI
-gemini

## 学んだこと
- モデルとマイグレーションを作成し、関連付けることの大切さを学んだがエラーとの戦いだったため自分の誤字に反省点があると感じた
- Tinkerを閉じずにコードを入力しているミスがあった為、閉じるなどの順番厳守の必要性を学んだ
- N＋１問題の解決のためにEager Loadingを使用することは理解したが、理解があいまいなため復習が必要だと感じた

## 動作確認
実際にページを開いてボタンをクリックしてみて正しい表記が出るかで動作確認を行った
